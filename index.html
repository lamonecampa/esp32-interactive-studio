04 / Panduan Belajar

Pahami sebelum menghafal
setup() dipakai untuk persiapan awal, misalnya mengatur pin sebagai OUTPUT. Fungsi ini dipanggil satu kali saat board mulai bekerja.

loop() dijalankan berulang selama ESP32 menyala. Instruksi digitalWrite() mengubah keluaran pin, sedangkan delay() menghentikan eksekusi sementara dalam milidetik.

Catatan teknis: versi ini adalah visualisasi edukatif untuk subset perintah Arduino, bukan compiler C++ atau emulator perangkat keras ESP32 penuh. Percabangan dan sintaks C++ kompleks belum dievaluasi sebagai program sungguhan.
